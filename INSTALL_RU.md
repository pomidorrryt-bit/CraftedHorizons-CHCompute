# CH Compute — установка и безопасность

CH Compute — **экспериментальная** система добровольных фоновых вычислений для Crafted Horizons. Она **не передает оперативную память игрока на Falix** и **не увеличивает TPS**. Результаты клиентов не используются в экономике, PvP, хранении мира и античите.

## Скачивание
Откройте вкладку **Actions**, выберите последний успешный запуск **Build CH Compute**, прокрутите до **Artifacts**. Там доступны архив с Windows-приложением и архив с плагином Paper. Бинарные файлы создаются автоматически из исходников GitHub. Для загрузки артефактов GitHub может потребовать вход в аккаунт.

## Игрок
1. Скачайте архив Windows, распакуйте и запустите CHCompute-Windows.exe. Приложение неподписанное, Windows может предупредить о неизвестном издателе — не отключайте антивирус.
2. Настройки откроются локально в браузере (127.0.0.1:18765).
3. Зайдите на сервер и введите /chcompute pair.
4. Введите выданный код, HTTPS-адрес и SHA-256 отпечаток **серверного** сертификата.
5. Выберите 1–2 потока, лимит нагрузки CPU и мягкий лимит RAM до 2048 МБ. Включите согласие; при новом запуске согласие снова выключено.
6. Остановить: выключатель или Exit в интерфейсе; отозвать связку: /chcompute revoke.

## Владелец Falix
1. Сделайте резервную копию игрового сервера.
2. Выделите **дополнительный TCP-порт** в Falix. Не используйте основной порт Minecraft.
3. Загрузите CHCompute-Paper-1.21.jar в plugins/.
4. Отдельно, **без публикации в GitHub**, создайте plugins/CHCompute/server.p12 и config.yml с приватным TLS-ключом и настройками. Самоподписанный сертификат допустим лишь при закреплённом SHA-256 отпечатке.
5. Пропишите выделенный порт и hostname в config.yml, затем разрешите HTTPS и перезапустите Paper.
6. Проверьте /chcompute info и журнал. Начните с одного добровольца.

**Не публикуйте server.p12, секреты и приватный архив Falix.** Приложение и плагин не готовы к использованию в качестве стабильной продакшен-системы без сквозных тестов.

Подробнее об архитектуре — в исходном архиве CHCompute-Source.zip.
